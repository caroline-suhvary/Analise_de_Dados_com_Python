# 📊 Análise de Faturamento & Inteligência Comercial (2021–2024)

Dashboard executivo e análise de dados transacionais de ERP utilizando **Python**, **DuckDB**, **Plotly** e **Streamlit**.

## 🔗 Acesso aos Projetos
- 🌐 **[Acessar Dashboard Interativo Online](https://painel-faturamento-comercial.streamlit.app/)**
- 📓 **[Ver Caderno de Análise e Consultas SQL](./analise_exploratoria.ipynb)**

## 🛠️ Tecnologias Utilizadas
- **DuckDB**: Consultas analíticas SQL de alta velocidade diretamente sobre arquivos colunares e tabulares.
- **Plotly**: Visualização de dados interativa (Pareto, dispersão de faturas e curva de concentração).
- **Streamlit**: Aplicação web interativa com filtros de competência, vendedor e categoria de serviço.
- **Pandas**: Manipulação e estruturação complementar de dados.
